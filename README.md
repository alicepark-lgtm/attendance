# 온라인 출석부 서명 — 설정 방법

파일 3개로 되어 있습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 참석자 서명 화면 + 관리자 화면(`?admin`) |
| `attendance.pdf` | 원본 출석부 (서명이 찍힐 PDF) |
| `Code.gs` | 구글 시트에 서명을 저장하는 Apps Script |

## 1. 구글 시트 + Apps Script (약 5분, 행사마다 새로 만들어도 되고 재사용해도 됨)

1. 새 구글 시트를 만듭니다 (이름 예: `11월5일 출석부 서명`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `Code.gs` 내용을 통째로 붙여넣습니다.
4. 맨 위 `ADMIN_KEY = '...'` 를 원하는 관리자 비밀번호로 바꾸고 저장합니다.
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포** → 권한 승인(“고급 → 안전하지 않음으로 이동” 한 번 승인) → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 2. index.html 에 URL 넣기

`index.html` 위쪽 `CONFIG` 의 `SCRIPT_URL: ''` 따옴표 안에 복사한 URL을 붙여넣습니다.
(비워 두면 “체험 모드”로, 서명이 그 기기에만 저장됩니다.)

## 3. 웹에 올리기 (GitHub Pages)

이 저장소(alicepark-lgtm/attendance)에 올라가 있습니다. `index.html` 을 고치면 다시 올리면 됩니다.
주소:
→ 참석자 링크: `https://alicepark-lgtm.github.io/attendance/`
→ 관리자 링크: `https://alicepark-lgtm.github.io/attendance/?admin`

## 4. 당일 사용

- **참석자**: 링크 접속 → 소속 선택 → 성명 선택 → 서명 칸에 서명 → **서명 제출**
  - 한 번 제출하면 같은 사람으로 다시 제출할 수 없습니다(다른 사람이 덮어쓰는 것 방지).
  - 다른 참석자의 서명 이미지는 보이지 않고 “서명 완료” 표시만 보입니다.
- **담당자**: `?admin` 링크 → 비밀번호 입력 → 현황 확인 → **완성본 PDF 내려받기**
  - 잘못 서명한 사람은 **초기화** 후 다시 서명하게 하면 됩니다.

## 다른 행사에 다시 쓰기

1. 새 출석부 PDF를 `attendance.pdf` 로 바꿉니다.
2. `CONFIG` 의 `TITLE`, `SUBTITLE`, `PEOPLE`(번호·소속·성명) 를 바꿉니다.
3. 표 모양이 다르면 `SIGN_COL`(서명 칸의 좌우 x 좌표)과 `ROW_LINES`(각 줄 가로선의 y 좌표, 위에서부터 pt)를 맞춰야 합니다.
4. 구글 시트의 `서명` 탭에서 이전 행사 행을 지우거나, 새 시트로 1번부터 다시 합니다.
